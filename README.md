# mascotas

Landing interactiva de Affinity Mascotas para calcular el precio de un seguro para perros y gatos.

La página y la dirección visual de la campaña «Su vida contigo» están en `index.html`. La guía para diseñar los componentes de atención está en `guia-de-estilo.html` y se enlaza desde el footer. La imagen de vista previa para compartir la web se guarda en `assets/social-preview.jpg`; mantén los tres recursos al desplegar el sitio en Vercel.
